# Аккорды

Тренажёр аккордов для фортепиано: сайт, который ставится на айфон как приложение. Учит строить аккорды по формуле, повторяет их по расписанию (FSRS, как в Anki), проверяет по-разному (построить, узнать, назвать ноты, на слух) и даёт играть прогрессии под метроном. Звук настоящего рояля.

Сайт: https://piano-akkordy.vercel.app/ (там же живёт API синхронизации). Зеркало без офлайна на GitHub Pages: https://warzikkr.github.io/piano-chords/

## Запуск

```bash
npm install
npm run dev
```

Открыть http://localhost:5173.

- `npm test` — тесты логики (теория аккордов, расписание, сессия).
- `npm run typecheck` — проверка типов.
- `npm run build` — сборка в `dist/` для любого статического хостинга (пути относительные).
- `npm run preview` — посмотреть сборку локально.
- `npm run deploy` — собрать и выложить зеркало на GitHub Pages (ветка `gh-pages`).
- `vercel deploy --prod` — выложить сайт и API на Vercel (пуш в `main` делает это сам).

## На айфон

Открыть сайт в Safari, нажать «Поделиться» → «На экран „Домой“». Дальше он работает как приложение, в том числе без интернета (на обычном хостинге).

## Синхронизация между устройствами

В «Настройках» есть раздел «Синхронизация»: кнопка «Создать токен» придумывает токен вида `k7m2-x9qa-4pzt` и даёт ссылку `…/?t=токен`. Открой ссылку на другом устройстве, и прогресс станет общим. Другой токен даёт отдельный прогресс. Копии сливаются: по каждому аккорду остаётся запись, где больше повторений.

Хранилище: функция `api/progress.ts` на Vercel кладёт JSON в приватный Vercel Blob под хэшем токена (сам токен не хранится). Сборка для другого хостинга указывает на этот API через переменную `VITE_SYNC_API`.

## Как устроено

- `src/theory` — ноты, типы аккордов, обращения, проверка ответов, прогрессии. Чистые функции с тестами.
- `src/learning` — порядок изучения (288 карточек на шести уровнях), FSRS, сборка сессии дня, варианты ответов, уроки.
- `src/state` — прогресс и настройки в localStorage, экспорт и импорт JSON, слияние копий и синхронизация через GitHub Gist.
- `src/audio` — сэмплер рояля на Web Audio, метроном.
- `src/components`, `src/screens` — клавиатура и экраны: Сегодня, сессия, Карта, Прогрессии, Справочник, Настройки.

Дизайн и план: `docs/superpowers/`.

## Звук

Сэмплы рояля из набора [tonejs-instruments](https://github.com/nbrosowsky/tonejs-instruments) (CC-BY 3.0), укороченные до 4 секунд и сжатые для быстрой загрузки на телефоне.
